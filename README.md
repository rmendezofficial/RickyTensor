# RickyTensor
Custom tensors library built from scratch. It has a tensor class, basic tensor operations, and layers used by transformers. The tensors also store their gradients and they are updated with backpropagation. The objective was to practice operations with tensors and their gradients to implement a mini GPT model. It was made to practice and it has some errors and a lack of clear documentation. Also, it does not totally resemble the architecture of the original GPT models, since the positional encoding is different and the hyperparameters such as the dimension of the embedding or the total number of layers and neurons is smaller in my implementation.
